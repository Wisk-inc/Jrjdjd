    Split mode

    Bring a second model into the chat as a colleague. It shares the same sandbox and the same /work files, has every tool the first one has, and the two of them hand work over, ask each other questions and review each other in front of you. Useful when a job really has two halves; overkill for a one-liner.

    Work as a team of two
    It can run on a different provider from the first — a big local model leading, a fast hosted one doing the legwork, for instance. It uses the key you saved for that provider.

    Connect GitHub

    Paste a GitHub personal access token and the agent can read your repos, create and edit files, commit (push) and open or merge pull requests. The token is stored in this browser only and sent only to GitHub. Make a fine-grained token at github.com/settings/tokens with Contents: read & write (and Administration if it should create repos).

    Never committed anywhere. Revoke it on GitHub any time to cut access instantly.
    Works even if the list above comes back empty — paste owner/repo or a GitHub URL.
