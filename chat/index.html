CorX Chat is an agentic AI workspace. It is an orchestrator: it puts the top available OpenAI models behind a single interface and adds the tools an ordinary chat window is missing — a real sandboxed terminal, web search with visible sources, image generation and understanding, file and archive editing, a code canvas, deep research, and memory that persists between sessions.

You sign in with your own ChatGPT account through the free Sign in with ChatGPT browser extension. CorX Labs never sees your credentials — they stay encrypted in your browser and are attached to each request from your side.

What it can do

A chat window that does the work.

A real terminal

Not a code block it hopes compiles. It installs packages, runs and tests code, makes API requests, and reads, writes, edits and deletes files — and you can open the panel and watch every command.

Web search you can audit

Ask it to look something up and it shows each site it consulted as it goes. Sources stay attached to the answer, so you can check the claim instead of trusting it.

Visible reasoning

Every answer carries a dropdown with the model's own thinking. Open it when you want to know why it reached a conclusion; leave it closed when you don't.

Images both ways

Send it a screenshot, a photo or a draft and it reads what's there. Ask for artwork, diagrams or mockups and it generates them.

Files and archives

Hand it a file — including a zip — and it opens it, edits what's inside, and hands it back. It builds new archives too, ready to download.

Canvas mode

Everything it generates is collected in a side panel, grouped by category and rendered in the code's own style — readable, and downloadable in one click.

It plans its own work

Give it a long job and it breaks the job into steps, works through them, and shows you the checklist as it goes — rather than stopping halfway and asking what's next.

Local and multilingual

It detects your country so research and locally-dependent answers are relevant where you are, and replies in the language you write in. Tell it to stop and it stops.

It remembers

Conversations and memory persist between visits, so you can close the tab mid-task and pick the same thread back up later.

Deep research

It checks whether a source deserves belief.

Ordinary search finds pages. Deep research reads several of them, compares what they claim, and weighs them against each other — checking whether a source's reasoning actually holds, whether its numbers agree with independent reporting, and whether it is primary or simply repeating somebody else.

Sources that fail that check are discarded rather than averaged in, and the ones that survive stay attached to the answer so you can follow them yourself. When a question depends on where you are — prices, regulations, availability — it researches for your region rather than defaulting to somewhere else.

Questions

Before you connect.

What is CorX Chat?

An agentic AI workspace from CorX Labs. It puts the top available OpenAI models behind one interface and adds the tools a chat window normally lacks: a real sandboxed terminal, web search with visible sources, image generation and understanding, file and archive editing, a code canvas, deep research and persistent memory.

Do I need an account?

Not a CorX one. You sign in with your own ChatGPT account through the free “Sign in with ChatGPT” browser extension. Your credentials stay encrypted in your browser — CorX Labs never sees or stores them.

Why is a browser extension needed?

The extension performs the OAuth handoff and keeps your credentials in your browser's own encrypted storage, so a hosted website never has to hold them. Without it there is no safe way for a web app to use your ChatGPT session. If it is already installed, this page detects it and takes you straight to authorisation.

Can it actually run code?

Yes — in a sandbox it drives itself. It installs packages, runs and tests code, makes API requests and manages files. Open the terminal panel to watch every command it runs rather than taking its word for the result.

Does it work in my language?

It detects the language you write in and answers in it, and detects your country so locally-dependent answers are relevant to where you are. Ask it to stop doing either and it will.

Is it free?

The interface is free. Model access comes from your own ChatGPT account, so which models you can reach and what limits apply are governed by your existing plan, not by CorX Labs.
