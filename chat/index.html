CorX Chat is an AI workspace that runs on your own ChatGPT account. Connect once with the official Sign in with ChatGPT extension and you get the top models your plan can reach, plus a real Python sandbox, live web search, image generation, file and zip handling, and a canvas of everything it builds.

It behaves as an agent by default — tell it to write code, fix a bug, research something or work through a long job and it does the whole thing. Its reasoning is available in a dropdown on every answer.

Real terminal

Full CPython in your tab. Installs packages, reads and writes files, and you see every command. It has no access to your computer.

Real search

It searches the web and reads live pages, showing each source it used so you can check the claim yourself.

Real files

Upload anything, including zips. It opens them, edits what is inside, and gives you a rebuilt file back.

Not built yet: a general Linux shell — the sandbox is a Python VM, so no git, node or apt. Full documentation.
